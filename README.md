# Учебный проект

Стартовый шаблон для отдельного учебного дизайн-проекта.

## Структура

- `assets/` — изображения и иконки.
- `fonts/` — шрифт EB Garamond и его лицензия SIL Open Font License.
- `styles/reset.css` — сброс стандартных стилей браузера.
- `styles/fonts.css` — локальное подключение EB Garamond.
- `styles/layout.css` — расположение блоков страницы.
- `styles/style.css` — цвета, текст и оформление элементов.
- `index.html` — главная страница; она подключает CSS-файлы отдельно из папки `styles/`.
