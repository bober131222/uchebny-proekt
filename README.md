# Новый проект

Стартовый шаблон для учебного проекта. Здесь пока нет конкретного дизайна: можно добавлять его в `index.html` и файлы внутри `styles`.

## Структура

- `assets/` — изображения и иконки.
- `fonts/` — файлы шрифтов проекта.
- `styles/reset.css` — базовый сброс оформления браузера.
- `styles/fonts.css` — семейства и настройки шрифтов.
- `styles/layout.css` — расположение крупных блоков страницы.
- `styles/style.css` — цвета, текст и оформление элементов.
- `index.html` — главная страница.

Шрифт `Isometra-Regular.ttf` в исходных файлах не найден. Когда он появится, положи его в `fonts/` и подключи через `@font-face` в `styles/fonts.css`.
